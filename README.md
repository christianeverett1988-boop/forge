# Forge

Personal fitness and nutrition app. A static PWA (plain HTML/CSS/JS, no build step) on GitHub Pages, with Firebase for sign-in and sync.

- First-time setup: [SETUP.md](SETUP.md)
- Pushing updates: [DEPLOY.md](DEPLOY.md)
- What's in each version: [CHANGELOG.md](CHANGELOG.md)
- Tests: `node tests/run.js`

Not medical advice. Calorie math: Mifflin-St Jeor (1990). Safe floors: Harvard Health Publishing (more cautious than NIH/NHLBI's low-calorie ranges). Exercise data: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain, Unlicense). Weight trend: exponential smoothing as in *The Hacker's Diet* (John Walker).
